# supabase 폴더

데이터베이스 변경 기록을 보관하는 곳입니다.

| 파일 | 설명 |
|---|---|
| `migrations/0001_init.sql` | 표, 보안 규칙(RLS), 기본 카테고리 |
| `checks/rls_check.sql` | 실행 결과 확인용 (읽기 전용) |

- 번호 순서대로 SQL Editor 에 붙여넣어 실행합니다.
- 이미 실행한 파일은 수정하지 않습니다. 바꿀 내용은 `0002_...sql` 처럼 새 파일로 만듭니다.
- 무료 플랜에는 자동 백업이 없으므로, 이 폴더가 "DB 구조의 백업"입니다.
